## 2. Strict Anti-Spoofing & Container Invariant

- **Zero Fake Containers**: Lumina never wraps a WebP or JPEG bitstream inside an `.avif` or `.psd` file extension. If the host browser lacks native AVIF encoding, the export engine alerts the user honestly rather than generating pseudo-containers.
- **Color Profiles**: ICC profiles for sRGB, Display P3, and Adobe RGB (1998) are embedded in accordance with ICC.1:2010 specifications.
